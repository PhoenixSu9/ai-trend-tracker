# Reports Directory

This directory contains weekly AI trend reports in Markdown format.

Files are automatically generated by the `scripts/generate_report.py` script.

Naming format: `weekly-report-YYYY-WNN-YYYY-MM-DD.md`

Where:
- YYYY: Year
- WNN: Week number (e.g., W50)
- YYYY-MM-DD: Generation date

Example: `weekly-report-2025-W50-2025-12-09.md`
